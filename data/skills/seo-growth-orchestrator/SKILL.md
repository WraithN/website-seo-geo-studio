# SEO/GEO Growth Orchestrator

Turn a vague traffic problem into a short, measurable acquisition workflow. Route specialist work to the bundled skills instead of attempting every task in one pass.

## Start

Collect only the missing inputs:

- Site or product URL, target market and language
- Conversion goal: sale, lead, signup, store visit, or brand visibility
- Current constraint: no traffic, wrong traffic, declining traffic, weak conversion, or weak AI visibility
- Available evidence: Search Console export, analytics, keyword list, competitor URLs, or page inventory

If live data is unavailable, continue with user-provided evidence and public pages. Label estimates as estimates; never invent search volume, ranking, traffic, or revenue.

## Route

Read [references/catalog.md](references/catalog.md) and choose the smallest useful chain:

1. **No baseline** — run `seo-project-setup`, then `seo-audit` or `seo-site-audit-pro`.
2. **Need topics and keywords** — run `keyword-research`, `keyword-clustering`, then `seo-content-brief`.
3. **Need to beat competitors** — run `competitive-landscape`, `competitor-analysis`, then `seo-competitor-pages` or `seo-content-brief`.
4. **Need content that earns traffic** — run `seo-content`, `seo-eeat-audit`, then `seo-ai-optimization` and `seo-geo` when AI-search visibility matters.
5. **Traffic dropped** — run `seo-gsc-drops`, `seo-gsc-content-decay`, `seo-gsc-indexing`, then the relevant technical or content skill.
6. **Technical blockers** — run `seo-technical`, then a focused skill such as `seo-core-web-vitals`, `seo-sitemap`, `seo-schema`, or `seo-internal-links`.
7. **Need local customers** — run `seo-local`, then `seo-page`, `seo-schema`, and `seo-gsc-opportunities`.
8. **Need reporting** — run `seo-gsc-overview`, `seo-gsc-compare`, then `seo-report`.

Stop after three specialist skills unless the user asks to continue. Give the result of each stage before starting the next.

## Deliver

Produce a compact acquisition brief:

1. Current diagnosis and evidence quality
2. Highest-value opportunity
3. Three actions ordered by impact and effort
4. Selected specialist skill chain
5. Metric and readback date for each action
6. Missing access or data that would improve confidence

Prefer commercial-intent pages and measurable opportunities when the stated goal is revenue. Do not promise traffic, rankings, leads, or revenue.
