- - severity: 严重

  - fix: 在首页 <head> 注入 JSON-LD：WebSite（name/url/alternateName + potentialAction 的 SearchAction，target 指向站内搜索 URL 模板）、Organization（name/url/logo/sameAs）、WebPage（name/description/inLanguage）。使用 Rich Results Test 与 Schema.org Validator 双校验

## structuredDataPlan
> 建议补充的结构化数据类型与理由

- - type: WebSite
  - priority: 高
  - reason: 站点级实体声明，配合 potentialAction 的 SearchAction 可争取站点链接搜索框富结果；同时强化 AI 搜索对站点实体的识别（有 schema 的内容进入 AI 答案的概率显著更高）
  - requiredProps: ["name","url","potentialAction(SearchAction: target, query-input)"]
- - type: Organization
  - priority: 高
  - reason: 声明品牌实体（名称、Logo、官方渠道 sameAs），支撑知识面板与实体消歧，是 E-E-A-T 的实体基础
  - requiredProps: ["name","url","logo","sameAs"]
- - type: WebPage
  - priority: 中
  - reason: 页面级实体，声明 name/description/inLanguage，与 WebSite 形成层级关系
  - requiredProps: ["name","description","inLanguage","isPartOf"]
- - type: BreadcrumbList
  - priority: 中
  - reason: 若首页之外的频道页/结果页存在层级导航，可输出面包屑富结果，改善 SERP 展示
  - requiredProps: ["itemListElement(position, name, item)"]
- - type: SearchAction（内嵌于 WebSite）
  - priority: 高
  - reason: 站内搜索入口的结构化声明，是获取 sitelinks search box 的唯一途径
  - requiredProps: ["target","query-input"]
